# 智能诊断与优化连续动效

打开 index.html 即可运行，无需安装依赖。也可以运行 `python3 -m http.server 8766`，浏览器访问 http://localhost:8766。

支持自动播放、暂停、重播、循环与播放速度调节。诊断进度共 4 项；完成后展示 2 项自动优化和 1 项手动补充。

## 动效参数

- 新条目：420ms，向上浮现 5px，已有内容保持稳定。
- 星星：600ms 转动 90°、停顿 600ms。
- 完成切换：星星沿当前角度再转动 90°，340ms 内缩到 80% 并淡出；对号延迟 120ms，从 70% 放大到 100%，180ms 淡入、380ms 落稳。
- 背景：紫色 #E3D3FF，blur 86.4px；蓝色 #C4EDFF，blur 82.8px。
